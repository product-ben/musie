# Eigene Aufnahmen

Hier kommen Lucias eigene Aufnahmen hinein, z. B. Waldklänge.

- Format: WAV oder FLAC (Originalqualität), mindestens 44,1 kHz. Eine kleinere Kopie für das Web (AAC/Opus) machen wir später.
- Dateiname sagt, was es ist und wo es war, z. B. `wald-morgen-2026-11.wav`.
- Für jede Datei eine Zeile in `../../AUDIO_LICENSES.md` (Quelle: „eigene Aufnahme“, Urheberin: Lucia, Datum).
- Ohne Stimmen, ohne Fahrzeuge, wenn möglich 2 Minuten oder länger, damit sich nichts hörbar wiederholt.
