8 · Nested theme override

Tokens are declared on :root, [data-theme], not :root alone. That is what lets any subtree flip theme correctly at any depth — a token declared only on the root would have collapsed to one value and merely inherited down. Every paired panel on this page relies on it.

Light subtree — data-theme="light"
Dark inside light — data-theme="dark"
Light inside dark inside light — three levels, still correct
