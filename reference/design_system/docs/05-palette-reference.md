# Palette reference (generated)

Radix-structured 12-step scales. Steps 1–8 curve-placed, 9/10 brand-anchored,
**11 / 12 / edge / press contrast-solved** against every surface a foreground can
legally land on — including other scales' tinted fills.

| Step | Radix use-class | Purpose |
|---|---|---|
| 1–2 | Backgrounds | App canvas, page surface |
| 3–5 | Interactive components | Tinted fill at rest / hover / active |
| 6–8 | Borders & separators | Subtle → decorative → hover |
| 9–10 | Solid colours | Filled buttons, meaningful graphics |
| 11–12 | Accessible text | Muted text (≥4.5:1) → high-contrast text (≥7:1) |
| edge | *(Musy addition)* | The only border that may carry a control boundary — solved ≥3:1 |
| press | *(Musy addition)* | Pressed solid, solved so the step-9 foreground stays legal |
