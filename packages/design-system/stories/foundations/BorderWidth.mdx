# Border width

Four widths. `--border-width-regular` is 1.5px rather than 1px because a
control boundary has to clear 3:1 (1.4.11) without looking heavy — and Layer 1
tokenised border colour and width but never *style*, which is why
`--border-style-dashed` had to be staged as amendment G2.
