# Breakpoints & grid

Mirror values only — **a media query cannot read a custom property**, so the
numbers live in the tokens for code to reference and in the JSON for Figma, and
the `@media` rules repeat them as literals. That duplication is unavoidable;
what matters is that both sides come from one recorded number.

# The viewport, and what a full-height view actually gets

The one group in Layer 1 whose value is a **measurement** rather than a
decision — so this section measures it live instead of printing the
declaration.

Sizing a view to the viewport is the mistake this family exists to stop: the
window is not what a view gets, because the app shell is sitting on the first
141 pixels of it. Everything below is the subtraction, written down once.
